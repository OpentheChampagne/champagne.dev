This is placeholder copy, written so the note layout has something real-shaped to set. It exists only on the `concept/editorial` branch.

Most portfolio sites are built like product pages: a hero, three cards, a footer. This one borrows from magazines instead. Every project is treated like a feature spread, with its screenshots and artifacts laid on the page the way an art director would lay out a story.

> A technology story told like a feature spread, not a template with my name on it.

## What changed

The text stays clean and readable. Everything around it is allowed to be a little imperfect:

- Screenshots and clippings sit at slight angles, held down with tape.
- Sticky notes carry the asides.
- Paper has grain, but nothing is distressed.

### A small piece of the code

```css
.piece { transform: rotate(var(--rot)); filter: var(--shadow); }
```

That's the whole idea. The rest is taste, and tape.
